v9 살아있는 세계 통합판

이번 버전은 이전에 따로 보강하던 시스템을 한 번에 통합합니다.

1. 다른 나라 상세 AI / 모바일 LOD
- 세계 모든 사람은 실제 개체 명부로 유지
- 멀리 있는 국가는 경량 연간/월간 시뮬레이션
- 관찰자가 3D 지역지도를 열면 해당 권역 사람 최대 모바일 36명 / PC 72명을 실제 3D 개체로 표시
- 지역 관찰 중 사람들은 도시 주변에서 움직임
- 아이폰에서 전세계 주민을 동시에 3D로 만들지 않아 성능 보호

2. 3D 도시 성장
- 국가 인구와 기반시설이 늘면 지역 3D 지도에서 집이 실제로 증가
- 40명 이상 시장
- 120명 또는 기반시설 45 이상 성벽/방어시설
- 해양권은 부두
- 산악/화산권은 광산 표현
- 실제 형성된 도시만 정착지 구조물이 확장

3. 경제 / 교역 / 외교 / 조약
- 곡물, 목재, 석재, 금속, 가축, 직물, 어업 자원
- 국가별 환경/노동인구에 따라 생산
- 서로 실제 접촉한 국가만 교역 가능
- 관계가 좋으면 통상협정 / 상호방위
- 자원 surplus/deficit을 교역으로 보정
- 관계 악화 시 조약 종료

4. 전쟁 실제화
- 동원 병력
- 보급
- 사기
- 기술/군사력/기반시설
- 전쟁 사망자를 실제 주민 개체에서 제거
- 패전국 기반시설/안정도 손실
- 전쟁 난민이 알고 있는 안전한 국가로 실제 이동
- 보급이 떨어지면 전쟁 종료 가능

5. 생태계
- 국가별 사슴 / 토끼 / 멧돼지 / 늑대 개체군
- 숲 / 토양 / 수자원 / 인간 압력
- 포식자-먹이 관계와 인간 개발로 개체수 변화
- 서식지 압박이 커지면 야생동물 농경지 침입 원인 기록

6. 원인 → 결과 → 기억 → 다음 역사
- 국가별 causal 로그
- 예: 전쟁 → 동원 → 사망 → 난민 → 안정도 하락
- 교역 시작 → 관계 상승 → 조약
- 서식지 압박 → 야생동물 침입
- 사건을 무작위 텍스트로만 쓰지 않고 실제 상태 변화 원인을 기록

7. 관찰자
- 모든 국가 인구/경제/기술/군사/생태/조약/전쟁/난민/실제 주민 명부 확인
- 서로는 탐사/접촉 전까지 모름
- 관찰자는 처음부터 전체를 볼 수 있음
- 3D 지역지도에서 나라가 실제로 커지는 모습 확인

기존 유지:
- 복실이 마을 순찰/동물 방어
- 움직이는 미니맵
- 지구급 40,075km 세계
- 장거리 원정
- 8권역/126도시
- 이명자 세계력 3년 1일 사망
- 행동분기 역사
- 동물 습격/몬스터 시대
