v10.6 300명 복구 + 타지역 마을 + 관찰자 이동수단 + 원정 추적

[세계 인구]
- 세계력 0년 실제 총인구 300명
- world-people.json의 실제 300명 국가 분포 사용
- 잘못된 30만 시작 모델 제거
- 기존 30만 세이브는 현재 연도에 맞춰 300명 기원 성장곡선으로 자동 재보정
- 이후 출생/사망/이주로 성장

[주민 분산]
- 주민마다 가족/개인 기준 실제 집 위치 배정
- 식사/휴식은 자기 집 주변
- 농부는 여러 밭 구획으로 분산
- 채석/벌목/약초/강물 작업도 넓은 작업권에 분산
- 회의/대화/학습도 한 점이 아닌 넓은 생활권 사용
- 탐험자는 외곽 여러 방향으로 이동
- 도시 재정비 뒤 주민 집 위치도 새 주거구획으로 갱신
- 중앙 한 점에 떼로 뭉치는 현상 완화

[사람 크기]
- 메인 주민/플레이어 38%
- 타지역 주민/관찰자도 38%
- 집 문보다 확실히 작게 보이도록 추가 축소

[타지역 마을]
- 30개 나라 모두 최소 1개 실제 초기 생활거점
- 126개 도시 전체가 즉시 생성되는 것은 아님
- 나머지는 후대 개척
- 작은 인구라도 2~7채 집, 길, 공동공간, 주민이 보임
- 수도 행정건물
- 해양: 부두 / 산악: 광산 / 평원: 밭 / 사막: 저수시설
- 미래 도시를 눌러도 허허벌판이 아니라 해당 국가의 실제 정착지로 이동

[관찰자 이동수단]
- 오른쪽 🐎 버튼
- 도보 ↔ 기승 전환
- 기승 시 로컬 이동 약 3.4배
- 다른 지역 3D 관찰맵에서도 3.4배
- 실제 말 3D 표시
- 전투 타겟 선택 시 자동 하마

[원정대 추적]
- 실제 감나무뜰 성인 주민 4~5명을 원정대에 배정
- 주민 이름이 원정 기록에 남음
- 원정 중 해당 주민은 감나무뜰 3D 화면에서 사라짐
- 오른쪽 🧭 버튼 → 진행 중 원정 목록
- 목적지 / 이동·귀환 상태 / 진행률 / 남은 날짜 / 거리 / 원정자 이름 표시
- 원정자를 누르면 세계지도에서 그 사람의 현재 이동점을 자동 확대 추적
- 목적지 도착 뒤 접촉 정보 획득
- 다시 실제 이동시간만큼 귀환
- 귀환하면 마을 주민 화면으로 복귀

- 복실이 계보
- 감나무 과수원
- 강/미니맵 동기화
- RPG 장비창 X 수정
