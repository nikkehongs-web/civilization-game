v9.6.1 실행 차단 오류 수정

정확한 원인:
- 초기 로딩 중 streamTerrainAroundPlayer(true)가 실행됨
- 이 함수가 updatePlayerLocationHud()를 호출함
- 위치 HUD가 regionViewActive / regionObserver 상태를 읽음
- 그런데 해당 let 변수 선언이 파일 훨씬 아래에 있었음
- JavaScript TDZ(Temporal Dead Zone) 때문에 시작 단계 ReferenceError가 발생할 수 있었음
- 이 오류는 시뮬레이션 보호모드가 시작되기 전이라 게임 전체 실행을 막을 수 있었음

수정:
- regionViewActive / regionViewName / regionObserver 등 지역 관찰 변수를 첫 사용보다 앞으로 이동
- 아래쪽 중복 선언 제거
- 모듈 시작 오류 / Promise 오류를 로딩 화면에 바로 표시하는 치명적 시작 오류 진단기 추가
- 정상 부팅 시 html data-civ-boot=ready 표시

기존 v9.6 기능 유지:
- 복실이 계보/짝/출산/성장/후손 경비
- ×50 / ×100 / ×300
- 미니맵-3D 지형 동기화
- 세계지도 직접 현지 이동
- 무경계 오픈월드
- 현재 위치 HUD
- 30개 국가 실제 인구
