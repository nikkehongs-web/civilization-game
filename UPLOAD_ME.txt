v10.5.1 동물 스케일 초기화 오류 수정

발생 오류:
Cannot access 'ANIMAL_WORLD_SCALE' before initialization.

정확한 원인:
- createAnimalModel()이 game.js 앞부분에서 정의됨
- populateWildAnimals()가 그 직후 즉시 실행됨
- createAnimalModel() 안에서 ANIMAL_WORLD_SCALE 사용
- 그런데 ANIMAL_WORLD_SCALE const 선언은 그보다 훨씬 아래에 있었음
- JavaScript const TDZ(Temporal Dead Zone) 때문에 Safari에서 시작 즉시 ReferenceError 발생

수정:
- HUMAN_WORLD_SCALE
- REGION_HUMAN_SCALE
- ANIMAL_WORLD_SCALE
- DOG_WORLD_SCALE
4개 스케일 상수를 동물 시스템보다 먼저 초기화하도록 이동
- 늦은 위치의 기존 선언 제거
- 중복 선언 없음
- 동물 생성 전에 ANIMAL_WORLD_SCALE이 반드시 초기화되는 순서를 정적 검사
