v8.1 아이폰 3D 검은화면 복구판

사용자가 초기화 후 다시 진행했는데도 검은 화면이 발생했기 때문에
구세이브 문제가 아닌 '한 하위 시스템의 예외가 전체 animation loop를 종료시키는 문제'에 대응했습니다.

핵심 수정
- 주민AI / 동물 / 전쟁 / 세계시뮬 / 미니맵 오류를 3D 렌더와 완전히 격리
- 한 기능이 오류 나도 다음 프레임 계속 실행
- 첫 프레임 전에 카메라 설정 + 3D 강제 렌더
- 하루 계산도 시스템별 보호 실행
- iPhone: antialias OFF
- iPhone: devicePixelRatio 최대 1.0
- iPhone: 실시간 shadow map OFF
- 외곽 맵 장식량 감소
- WebGL context lost 감지
- 오류 발생 시 화면 하단에 어떤 시스템인지 5초 표시
- 이명자 세계력 3년 1일 사망 유지
- 복실이 / 동물 / 확장맵 / 관찰자 전체국가 인구 / 분기 역사 / 전쟁 유지
