v11 전체 통합판

[세계지도 현재 위치]
- 세계지도에 항상 빨간 📍 + 노란 펄스 원으로 '나' 표시
- 감나무뜰에서는 감나무뜰 시작 도시 위치
- 타지역 3D 관찰 중에는 실제 그 지역의 현재 위치를 세계좌표로 역산해 표시
- 세계지도 상단에 '📍 나 · 국가 · 현재 지명' 배지
- 세계지도 '📍 나' 버튼으로 현재 위치 자동 확대
- 타지역에서 세계지도 버튼을 눌러도 지역 관찰을 종료하지 않음
- 세계지도를 닫으면 원래 타지역 현지 화면 그대로 복귀
- 다른 도시로 이동할 때만 기존 지역관찰을 종료하고 새 지역으로 전환

[몬스터 실험/변이 계통]
- 6개 프로젝트 실험 원본 데이터
- PROJECT ARES / VELOX / MYCEL / NERVA / OSSIS / ECHO
- 일반체 → 변이체 → 엘리트 → 프로토타입 계통 기록
- 재생조직 / 신경과속 / 골격경화 / 폭주반응 / 흡수세포 분기 기록
- 발견 연도 / 처치 횟수 / 최고 레벨 / 최고 위험점수
- 🧪 계통 버튼으로 확인

[위험등급]
5급 / 4급 / 3급 / 2급 / 1급 / 특급
- 몬스터 레벨, 등급, 추가변이로 절대 위험점수 계산
- 전투 HUD에 위험등급/점수 표시
- 계통도에 해당 계통의 최고 위험등급 기록

[이동수단 발전]
- 🚶 도보 1×
- 🐎 기승 3.4×
- 🛒 수레 4.8× (10년 또는 목공기초)
- 🚐 마차 6.4× (25년 이후)
- 이동 버튼을 누르면 현재 해금된 수단을 순환
- 전투 시 기존처럼 이동수단 해제 가능

[타국 실제 생활]
- 타국 주민이 무작위로 계속 떠도는 방식 제거
- 주민별 집/일터를 가지고 집↔일터 생활 반복
- 농사/목축/공방/시장/채집 역할 분배
- 작은 취락도 최소 집/길/공동공간이 보임

[마을 → 도시 재건축]
- 인구에 따라 야영지 / 촌락 / 소도시 / 도시 / 광역도시
- 도로망 확대
- 소도시부터 광장/시장 생성
- 도시 단계부터 행정건물
- 기존 주거/농경 구역 분리 유지

[장기 안정화]
- 중복 주민 제거
- 주민 나이 105세 상한
- 개인 기억/국가 역사/이벤트 데이터 크기 제한
- foundedCities 중복/깨진 ID 정리
- 3년 이상 비정상 장기전 강제 종료
- 인벤토리/로그 크기 제한
- 매년 안정화 검사

[기존 유지]
- 세계력 0년 실제 300명 시작
- 사람 38% 크기
- 주민 생활권 분산
- 30개 나라 초기 정착지
- 관찰자 원정 주민 추적
- 복실이 계보
- 감나무 과수원
- 강/미니맵 동기화
- RPG
- x300 배속
