v8.6 세계 전체 실제 인구 + 관찰자 국가 성장판

핵심
- 세계력 0년 총인구 300명을 실제 사람 개체 300명으로 생성
- 에르단/감나무뜰의 시작 주민은 기존 공식 주민을 그대로 세계 인구 명부에 연결
- 나머지 국가는 가구/나이/성별/직업/도시를 가진 실제 사람으로 시작
- 출생이 발생하면 실제 아기 개체가 추가됨
- 사망하면 실제 사람 개체가 사망 처리됨
- 나이를 먹고 아이→견습→성인 직업으로 변화
- 세계 총인구는 더 이상 임의 숫자가 아니라 살아 있는 사람 개체 수의 합

관찰자
- 모든 국가의 인구와 주민 명부를 접촉 여부와 관계없이 확인
- 국가 클릭 시:
  현재인구 / 전년대비 / 출생 / 사망
  아이 / 성인 / 노인 / 가구 / 노동인구
  식량 / 기술 / 기반시설 / 군사 / 안정 / 탐사
  정착도시 수 / 최대 도시 슬롯
  그 나라가 알고 있는 다른 나라 수
  최근 12년 인구 성장 막대
  최근 주요 사건
  실제 주민 명부 20명씩 페이지 이동

나라들은 서로 모름
- 각 국가는 처음에는 자기 나라만 알고 시작
- 탐사 범위가 실제 거리까지 닿아야 다른 나라와 첫 접촉
- 첫 접촉 후에야 교역/충돌/전쟁 가능
- 외부 국가 전쟁도 서로 알고 있는 국가끼리만 발생
- 관찰자는 이 과정을 처음부터 모두 볼 수 있음

나라 성장
- 실제 인구/노동인구/식량/기술/기반시설에 따라 성장
- 인구와 기반시설이 커져야 새 도시 정착지가 생김
- 기존처럼 '200년이 됐으니 자동으로 126도시'가 아니라 실제 성장 결과로 도시가 늘어남
- 국가 단계: 소집단 → 야영 취락 → 정착촌 → 촌락권 → 도시국 → 소국 → 국가권

기존 기능 유지
- 움직이는 미니맵
- 8개 3D 지역지도
- 지구급 40,075km 세계
- 장거리 원정
- 복실이 마을 순찰/동물 방어
- 동물/습격/전쟁
- 이명자 세계력 3년 1일 사망
- 행동에 따른 문명 역사 분기
