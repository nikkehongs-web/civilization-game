v9.5 미니맵 완전동기화 + 세계지도 직접이동 + 조이스틱 상향

1. 미니맵 ↔ 실제 3D 맵 동기화
- 기존 미니맵의 임의 녹색 배경 제거
- 3D 오픈월드가 실제 사용하는 chunkBiome() / chunkSeed()를 미니맵도 그대로 사용
- 같은 150m 청크 경계
- 같은 바이옴: 들판 / 숲 / 호숫가 숲 / 구릉 / 초원 / 습지
- 같은 결정론적 연못 위치와 크기
- 같은 나무 / 관목 / 바위 생성 위치
- 같은 탐사표지 위치
- 감나무뜰 근처에서만 실제 마을 강/길/밭을 덧그림
- 플레이어/주민/복실이/동물/적대개체 좌표도 기존대로 실제 월드좌표 사용
- 미니맵 제목: '3D 지형 동기화'

2. 세계지도 클릭 직접 이동
- 세계지도 위 도시를 한 번 터치 → 해당 도시 3D 현지로 즉시 관찰 이동
- 대륙/권역 땅을 한 번 터치 → 해당 권역 3D 현지로 즉시 이동
- 섬/화산군도도 도시 섬 좌표 기준으로 직접 선택
- 권역 범례 버튼을 눌러도 해당 3D 지역으로 즉시 이동
- 바다를 잘못 누르면 즉시 이동하지 않고 가까운 권역 정보 표시
- 관찰자 이동은 주민 첫 접촉/외교/여행시간과 완전히 별개

3. 조이스틱 위치
- 기존 화면 맨 아래에서 약 55~65px 위로 이동
- iPhone safe-area까지 포함해 하단 홈바와 더 멀어짐
- 작은 화면에서도 별도 보정

기존 유지
- 관찰자 전세계 이동
- 현재 위치 HUD
- 무경계 오픈월드
- 30개 국가 실제 인구
- 8권역 / 126도시
- 복실이 / 동물 / 전쟁 / 국가성장
