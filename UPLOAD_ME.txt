v9.2 연속 오픈월드 맵

핵심 수정
- 기존 로컬맵의 보이지 않는 끝벽 제거
- ±285m / ±235m 강제 clamp 제거
- 조이스틱 이동 제한 제거
- 바닥 터치 이동 제한 제거
- 카메라 드래그 제한 제거
- 미니맵 관찰 위치 제한 제거

연속 지형 스트리밍
- 플레이어가 이동하는 방향으로 150m 지형 청크를 실시간 생성
- 현재 위치 주변 5x5 청크만 유지하고 멀어진 청크는 메모리에서 제거
- 따라서 오래 걸어도 맵 끝/허공이 나오지 않음
- 아이폰은 청크당 오브젝트 수를 낮춰 성능 보호
- 숲 / 초원 / 구릉 / 습지 / 호숫가 / 들판 바이옴
- 나무 / 관목 / 바위 / 언덕 / 연못
- 드물게 탐사표지 생성

길 찾기
- 감나무뜰은 원점에 그대로 존재
- 미니맵/귀환 HUD로 중심 방향과 거리 유지
- ⌂ 버튼으로 감나무뜰까지 자동 이동 가능
- 멀리 가도 현재 위치와 중심까지 거리를 표시

주의
- 세계지도(40,075km 행성)와 로컬 3D 탐사맵은 축척이 다름
- 로컬맵은 마을 주변을 연속으로 걸어다니는 실제 3D 공간
- 국가간 수천 km 이동은 세계 원정 시스템으로 처리

기존 유지
- 캐릭터 이미지
- 복실이 마을 순찰/동물 방어
- 국가 인구/전쟁/관찰자
- 세계지도/8권역/126도시
- 이명자 3년 1일 사망
