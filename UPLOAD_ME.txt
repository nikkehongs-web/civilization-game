반드시 ZIP 안 파일을 전부 GitHub 저장소 최상위에 덮어쓰세요.

이번 수정
1. 일반 동물
- 시작부터 야생 토끼 4 / 사슴 3 실제 3D 이동
- 몬스터와 완전히 별개
- 사육장 완성 후 닭 4 / 염소 2 실제 생성
- 사육 주민 행동이 동물 돌봄과 생산에 연결
- 미니맵에 야생/사육동물 표시

2. 로컬 3D 맵 실제 확장
- 4단계 확장
- 탐사 진행도 + 연도 + 문명단계로 외곽 지형 타일이 실제 등장
- 1년/3년/7년 저장은 자동으로 더 넓어진 지도 반영
- 확장된 땅도 터치 이동 가능
- 조이스틱과 카메라도 확장 경계까지 이동 가능

3. 화면 드래그
- 기본: 한 손가락 드래그 = 화면/맵 이동
- 오른쪽 ✥ 버튼을 누르면 ↻ 회전 모드 전환
- 두 손가락 = 회전 + 핀치 확대/축소
- ◎ = 내 캐릭터로 카메라 복귀

4. 세계지도
- 오른쪽 아래 🌍 버튼 항상 표시
- 상단 🌍 버튼도 유지
- 8권역 / 126도시
- 현재 세계 / 세계력 200년 기준 전환
- 드래그 / 핀치 / 도시·권역 터치 상세
- 현재 탐사·항해 진행과 연동
