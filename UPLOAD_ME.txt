v10.2 실험체 RPG 전투 통합판

[몬스터 컨셉 전면 수정]
몬스터는 자연 발생종이 아니라 과거 생체 실험으로 발생한 변이 실험체.
6개 실험 계통:
A-17 근육증식체 — 거대한 인간형 근육 변이
B-04 절단변이체 — 빠른 사족/칼날 전완
C-11 포자숙주 — 부풀어 오른 균사/포자 숙주
D-09 신경전도체 — 가늘고 긴 전도 조직/발광 코어
E-22 골각변이체 — 거대한 사족형/외부 골각
F-01 회수실패체 — 인간형 강화 실험 회수 실패체

이제 공통 monster.webp를 모든 몬스터 몸에 덮지 않음.
각 실험체는 실제로 다른 Three.js 체형/실루엣/발광색을 가짐.

[위험 등급]
일반 / 변이 / 엘리트 / 프로토타입
등급별 HP/공격/크기/보상/아이템 확률 차이.

[추가 변이]
재생조직 / 신경과속 / 골격경화 / 폭주반응 / 흡수세포.
실제 전투 수치와 행동에 반영.

[레벨 성장]
레벨업마다:
- 기본 공격력 +4
- 기본 최대HP +14
- 스킬포인트 +1
- 레벨 자체가 방어/치명/회피에도 소폭 반영
- LV5부터 5타마다 강화 공격
- LV15부터 주기적 강공격
장비와 스킬을 합친 실제 최종 공격/방어/HP가 HUD에 표시됨.

[돈]
몬스터 처치 시 은화 획득.
엘리트/프로토타입일수록 은화 증가.
아이템 판매로 추가 은화 획득.
은화로 회복약 구입/장비 강화.

[아이템]
무기 / 방어구 / 장신구 3슬롯.
희귀도:
일반 / 고급 / 희귀 / 영웅 / 전설.
아이템은 몬스터 레벨과 위험등급에 따라 능력치가 증가.
인벤토리 최대 60개, 초과 드롭은 자동판매.

[강화]
장착 장비를 은화 + 생체파편으로 강화.
강화 시 공격/방어/HP 등 실제 수치 증가.

[재료]
생체파편 / 실험 데이터 조각.
생체파편은 장비 강화에 사용.

[회복약]
몬스터 드롭 또는 은화로 구입.
사용 시 최대HP 48% 회복.

[스킬]
레벨업 스킬포인트로 직접 선택:
- 근력 단련: 랭크당 최종 공격 +5%
- 생존 본능: 랭크당 최대HP +4%, 방어 증가
- 치명 감각: 랭크당 치명타 +2%
- 생체 흡수: 랭크당 가한 피해 1.2% 흡혈

[실험체 도감]
처음 처치하면 실험기록이 복원되고 연대기에 기록.
장비창에서 각 실험체의 실험 목적/변이 결과/처치수를 확인.

[전투 HUD]
선택한 실험체:
- 실험 코드
- 위험 등급
- 이름
- 레벨
- 현재/최대 HP
- 추가 변이
표시.

기존 유지:
- 문명/국가/가계도/정치/전쟁/계절/날씨
- 복실이 후손
- ×300 시간배속
- 세계지도 직접 이동
- 미니맵/3D 동기화
- 사람 크기 72%
