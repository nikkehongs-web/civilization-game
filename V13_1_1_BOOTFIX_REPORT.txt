《문명》 v13.1.1 시작오류 수정 보고서

발생 오류:
Cannot access 'REGION_KNOWLEDGE_FOCUS' before initialization.

정확한 원인:
- initialCountryState()는 최초 state를 만드는 과정에서 즉시 실행됨.
- initialCountryState() 내부에서 REGION_KNOWLEDGE_FOCUS를 사용함.
- REGION_KNOWLEDGE_FOCUS const 선언은 기존 game.js 약 2947행에 있었음.
- JavaScript const TDZ 때문에 Safari에서 최초 state 생성 즉시 ReferenceError 발생.

수정:
- REGION_KNOWLEDGE_FOCUS 선언을 INITIAL_REGION_COMMUNITIES 바로 뒤로 이동.
- initialCountryState()보다 반드시 먼저 초기화되도록 순서 고정.
- 기존 뒤쪽 선언 제거.
- 중복 선언 없음.

동일 유형 전수검사:
- 최초 state 생성 위치 이전에서 참조되지만 그 뒤에서 선언되는 UPPER_CASE 전역 const를 전수 검색.
- 남은 후보 0건.

검사:
PASS | REGION_KNOWLEDGE_FOCUS < initialCountryState < state 생성 순서
PASS | JavaScript 4개 파일 node --check
PASS | JSON 7개 파싱
PASS | REGION_KNOWLEDGE_FOCUS 중복 0
PASS | 시작 인구 300 설정 유지
PASS | 금지 캐릭터/ID 없음

주의:
- 이 검사는 정적 부팅순서/문법 검사이며 iPhone Safari 실기 렌더링 테스트는 아님.
